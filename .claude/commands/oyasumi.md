# Longevity Navigator｜おやすみ｜日誌まとめ＋保存

ユーザーが「おやすみ」と言ったら、今日の完了タスクを日誌にまとめて保存する。

---

## 実行手順

### STEP 1：今日の作業内容を収集する

以下のソースから今日の作業を特定する：

1. **gitログ**：`git log --oneline --since="today 00:00" --until="tomorrow 00:00"` で今日のコミットを確認
2. **ファイル変更**：`git diff --stat HEAD~10` で直近の変更ファイルを確認
3. **新規ファイル**：今日の日付で更新されたファイルをチェック
4. **会話の履歴**：このセッション内で実行したタスクを振り返る

### STEP 2：進捗状況を確認する

1. `note/第*回_*/` フォルダをGlobで一覧取得し、最新回数を特定
2. `ROADMAP_2026.md` を読み、今日予定されていたタスクの完了状況を確認
3. 有料noteの進捗を確認

### STEP 3：日誌を作成・保存する

保存先：`C:\Users\masas\product\2nd-Brain\04_アウトプット\Longevity\daily_logs\YYYY-MM-DD.md`

```markdown
# YYYY-MM-DD（曜日）日誌

## 完了タスク
- [x] [完了したタスク1]
- [x] [完了したタスク2]
- [x] [完了したタスク3]

## 未完了・繰越
- [ ] [未完了タスク1]（理由：〇〇）

## 今日の成果物
- [生成・公開したファイルやコンテンツ]

## 数値メモ
- note公開済み：第N回まで
- 素材完成：第M回まで
- ローンチまで：あとX日

## 明日の優先タスク
1. [最も重要なタスク]
2. [次に重要なタスク]

## ひとこと
[今日の感想やメモ（自動で1行生成）]
```

### STEP 4：おやすみメッセージを表示する

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
🌙 おつかれさまでした！ YYYY年MM月DD日（曜日）
━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 今日の完了タスク
  ✓ [タスク1]
  ✓ [タスク2]
  ✓ [タスク3]

📈 進捗サマリー
  note公開済み：第N回（目標：4/18までに全7本＋有料note）
  ローンチまで：あとX日

📝 日誌保存先
  daily_logs/YYYY-MM-DD.md

🌅 明日の最優先タスク
  → [明日最初にやるべきこと]

おやすみなさい！今日も一歩前進しました 💪
━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### ルール

- 日誌は `daily_logs/` フォルダに日付ファイル名で保存する（フォルダがなければ作成）
- 完了タスクはロードマップ予定と実際のgitログ・作業内容を照合して判定する
- 未完了タスクは翌日の「おはよう」で繰越表示される
- 「ひとこと」は作業内容から自動で1行生成する（マーシーの進捗を前向きに評価）
- 前日の日誌が存在しない場合でもエラーにしない
