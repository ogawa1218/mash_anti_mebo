# /podcast-to-note-assets

ポッドキャストの台本・テーマ・構成メモを受け取り、note公開に必要な全アセットを一括生成するスキル。

## 使い方

```
/podcast-to-note-assets
```

実行後、以下のいずれかを貼り付けてください：
- ポッドキャスト台本（テキスト）
- エピソードのテーマ・概要メモ
- 収録済みの構成メモ

---

## 生成するアセット一覧

以下を全て生成し、`2ndBrain/product/longevity/note/YYYYMMDD-{slug}/` 以下に保存する。

### ファイル構成

```
YYYYMMDD-{slug}/
├── note-article.md     # note本文
└── note-assets.md      # 全アセット一式
```

---

## note-article.md の構成

マーシーのnote記事テンプレートに従い以下の構成で生成：

1. **はじめに**（共感型：頑張ってるのに結果が出ないあなたへ）
2. **結論3つ先出し**
3. **第1章**：テーマの核心（驚き・問いかけ型）
4. **第2章**：100kg時代の実体験・失敗談（共感型）
5. **第3章**：+1習慣3つ（問いかけ型）
6. **第4章**：挫折しない連携設計（逆説型）
7. **第5章**：習慣が変える未来（驚き型）
8. **よくある質問**（Q×3）
9. **行動設計**（今日の1アクション＋習慣スタック）
10. **まとめ**＋著者プロフィール＋免責事項

**文字数目標：5,500〜7,000字**

**薬機法チェック（生成後に自動適用）：**
- 断定表現 → 「〜可能性がある」「〜しやすいとされています」「〜やすくなります」
- 効果効能の断言 → 「〜と言われています」「個人差があります」を付記
- 「治る」「改善する」等の断定 → 削除または軟化

### セクション2：リード文（note冒頭コピー）

- 共感→驚き→約束の3段構成
- 150字程度

### セクション3：見出し画像テキスト案（3案）

- 案①問いかけ型
- 案②逆説型
- 案③行動提案型

---

### セクション4：ハッシュタグ

- 20個程度（テーマ系＋マーシー固定タグ）
- 固定タグ：`#健康ラジオ #マーシー #仕組みで変える`

---

### セクション5：X（Twitter）投稿文（10案）

各案は200〜280字以内。ハッシュタグ3個まで。

| 案 | 型 | 説明 |
|---|---|---|
| ①  | 問いかけ型 | 読者の悩みから入る |
| ② | 驚き型 | 意外な事実・逆説から入る |
| ③ | 行動提案型 | 今すぐできる1アクション |
| ④ | 数字実績型 | 100kg→68kg・サブ3の実績で信頼構築 |
| ⑤ | 罠暴露型 | 100kg時代の失敗談リスト |
| ⑥ | Before/After対比型 | 過去と現在の習慣を対比 |
| ⑦ | 仕組み解説型 | 「意志力じゃなく仕組みで」を体現 |
| ⑧ | リカバリー設計型 | 崩れた日の翌日設計 |
| ⑨ | クイズ型 | Q&A形式でエンゲージメント獲得 |
| ⑩ | まとめ＆CTA型 | 3ポイントまとめ→note誘導 |

全案末尾に `[note URL]` プレースホルダーを挿入。

---

### セクション6：ポッドキャスト説明文（各プラットフォーム共通）

- 300字以内
- 今日のテーマ・3つの習慣・1アクション・noteURL誘導を含む

---

### セクション7：LINE/メルマガ配信文

- 200字以内
- 3つの+1習慣の箇条書き＋note誘導

---

### セクション8：note挿入画像 設計書（5点）

各画像はCanva等で制作。**挿入箇所はnote本文の該当セクション直前**に配置。

各画像仕様を以下の形式で出力：

```
### 画像①：[画像タイトル]
**挿入箇所：[note本文の具体的な段落・セクション名]**

| 項目 | 内容 |
|---|---|
| サイズ | [px指定] |
| 背景色 | [色名（HEXコード）] |
| メインテキスト | [文言] |
| サブテキスト | [文言] |
| 装飾要素 | [アイコン・イラスト案] |
| ブランド | [マーシーのロゴ/署名位置] |
```

**5点の構成：**
- 画像①：見出し画像（OGP兼用）→ タイトル直下
- 画像②：テーマの核心を示す対比図解 → 第1章末尾
- 画像③：100kg時代の失敗インフォグラフィック → 第2章末尾
- 画像④：+1習慣チェックリスト → 第3章タイトル直下
- 画像⑤：習慣スタック設計図 → 行動設計セクション内

---

### セクション9：X投稿用 画像仕様（10案対応）

推奨サイズ：1200×675px（16:9）

以下の一覧表形式で出力：

| 案 | 画像タイプ | メインテキスト | サブテキスト | 背景 | アクセントカラー |
|---|---|---|---|---|---|
| ①〜⑩ | ... | ... | ... | ... | ... |

**共通ルール（全画像）：**
- フォント：見出しはゴシック太字、サブはやや細め
- ブランドカラー：グリーン系（#1a3a2a）またはネイビー（#1a2340）ベース
- 署名：右下または左下に「マーシー @mashy_健康習慣」（小）
- 可読性：スマホサムネ想定、メインテキストは40px相当以上

## QA チェックリスト（生成後に自動実行）

生成後、以下5点を自動チェックし、問題があれば即修正してから保存：

- [ ] 薬機法：断定表現がないか
- [ ] 文字数：5,500字以上あるか
- [ ] 構成：10章構成になっているか
- [ ] CTA：「今日の1アクション」が明確か
- [ ] ブランド：マーシーのモットー・実績が入っているか

---

## 出力後のアクション

1. `note-article.md` と `note-assets.md` を保存
2. git add → commit → push（ブランチ：`claude/longevity-news-podcast-L3ROS`）
3. 完了報告：生成したアセット一覧と確認すべき点をサマリーで表示
