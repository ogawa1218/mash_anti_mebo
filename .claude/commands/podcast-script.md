# Longevity Navigator｜Podcast台本作成者｜台本 + 概要欄 自動生成

このコマンドは、研究トピックまたはnote記事を元に、
**stand.fm向けの台本**と**概要欄（ショーノート）**を自動生成します。

## 保存先

| 保存先 | パス |
|---|---|
| Podcast台本 | `Podcast/台本/YYYYMMDD_[トピック名].md` |
| stand.fm概要欄 | `Podcast/stand.fm概要欄/YYYYMMDD_[トピック名].md` |

---

## 実行手順

### STEP 1｜入力を受け取る

引数がある場合：その引数をトピックまたは記事として使う
引数がない場合：最新の `note/research_stock.md` から活用度★★★★★のトピックを1件選ぶ

---

### STEP 2｜台本を生成

**長さの目安：** 15〜20分（文字数2,500〜3,500字）

**マーシーのPodcastスタイル：**
- 一人語り（インタビュー形式ではない）
- 口語体・話し言葉（「〜なんですよね」「〜じゃないですか」）
- データと体験談を交互に
- 聴いているだけで理解できる（図解なしで成立させる）
- テンポよく・ダレない展開

**台本構成（必須8ブロック）：**

```
[OP] オープニング（30秒）
・「こんにちは、マーシーです」
・今日のテーマを一言で予告
・「最後まで聴いてください」

[1] 問題提起（2分）
・「健診でE判定をもらった経験がある人に届けたい話です」
・リスナーの感情に刺さる問いかけ
・「俺もそうだった」という共感

[2] 今日の結論（1分）
・先に結論を言う（Podcast は流し聴きが多いため）
・「今日一番伝えたいのは〇〇です」

[3] 研究データ（3〜4分）
・「〇〇大学の研究によると」で出典を明記
・数字を使う（でも複雑にしない）
・「これ、どういうことかというと」で噛み砕く

[4] マーシーの体験談（2〜3分）
・実体験と研究を結びつける
・「100kgだった俺が変わったのはここだった」

[5] 具体的な行動手順（3分）
・「今日からできること3つ」
・超具体的（商品名・時間・量）

[6] よくある失敗パターン（2分）
・「ここで間違える人が多い」
・「俺も最初はこれをやっていた」

[7] まとめ（1分）
・3行で要約
・「続けることが一番大事」

[CL] クロージング（1分）
・「今日もありがとうございました」
・noteリンクへの誘導
・「スキ・コメントもらえると励みになります」
・「次回は〇〇について話します」
```

## マーシーのPodcastトーン例

```
❌ 堅い（やめる）：
「最新の研究によって、マグネシウムの摂取がメタボリックシンドロームに有効であることが示されています」

✅ 自然（使う）：
「正直に言うと、俺も最初はマグネシウムなんてそんな大事だと思ってなかったんですよ。
でも数字を見て、ちょっと待ってってなった。日本人の40代男性、毎日140mgも足りてないって。
そりゃインスリン抵抗性が上がるよ、って話なんです。」
```

---

## 注意事項

- 医療的断言はしない（「個人の体験・研究の紹介」として）
- 出典は「〇〇大学の〇〇年の研究によると」の形で明記
- 聴き手が流し聴きでも理解できる構成にする
- 専門用語は必ず「つまり〜」で噛み砕く
- エピソードは必ず「今日からできる行動」で締める
