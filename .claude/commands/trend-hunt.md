# Longevity Navigator｜世界バズコンテンツ発掘 → マーシー版翻案

このコマンドは、不老長寿・健康・ダイエット領域で**世界的にバズっているコンテンツ**を
Web検索で発掘し、マーシーのブランドとペルソナに合わせて翻案します。

## 保存先

| 保存先 | パス |
|---|---|
| トレンドレポート | `trend_hunts/trend_hunt_YYYYMMDD.md` |
| X投稿候補 | レポート内に含む |
| note活用メモ | レポート内に含む |

---

## 実行手順

### STEP 1｜検索ジャンルを決める

引数がある場合：その引数をジャンルとして使う
引数がない場合：以下のデフォルトで検索

```
デフォルト検索ジャンル：
- 不老長寿・Longevity（Peter Attia / Andrew Huberman / Bryan Johnson等）
- メタボ・肥満・ダイエット（GLP-1 / 間欠断食 / ゾーン2等）
- 最新サプリ・栄養学（NMN / クレアチン / マグネシウム等）
```

---

### STEP 2｜世界のバズコンテンツを検索

以下のソースを対象に検索する：

**英語圏（必須）：**
- X (Twitter)：フォロワー10万人以上の健康・長寿アカウントのバズ投稿
- YouTube：直近1ヶ月で100万再生以上の健康系動画
- Reddit：r/longevity / r/nutrition / r/ketodiet のホット投稿
- Substack：Andrew Huberman / Peter Attia / Rhonda Patrick の最新記事

**検索クエリ例：**
```
site:twitter.com longevity health viral 2025
"Peter Attia" OR "Andrew Huberman" OR "Bryan Johnson" latest post
reddit r/longevity trending 2025
health longevity viral content 2025
```

収集する情報：
- コンテンツの種類（X投稿 / 動画 / 記事）
- 発信者名・フォロワー数
- エンゲージメント数（いいね・RT・再生数）
- 内容の要約（なぜバズったか）
- 日本未上陸かどうか

---

### STEP 3｜Top3を選定・マーシー版に翻案

**選定基準（優先順）：**
1. ペルソナ（田中 健二42歳・健診E判定メタボ）への関連度
2. 日本でまだ広まっていない情報か
3. エンゲージメントの高さ

**翻案ルール：**
- マーシーの一人称・実体験を加える（「俺も最初は〜だと思ってた」）
- 数字・データは日本人向けに換算（lbs→kg, miles→km等）
- CLAUDE.mdのトーン＆マナーに従う
- 「意志力ではなく仕組み」の視点を加える
