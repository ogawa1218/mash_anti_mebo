## 投稿3/10｜解決策

```
英国の大規模糖尿病研究（UKPDS）が示すこと。

体重が大きく変わらなくても、
食事・生活習慣を変えれば
HbA1c（血糖の長期指標）は改善する。

つまり、
体重が動かない＝失敗
ではない。

見る場所を変えれば、続けられるようになる。

↓続き（4/10）
```

## 投稿9/10｜深掘り

```
食後眠気が「血糖スパイク」のサインである理由。

血糖値が急上昇する
→ インスリンが大量分泌される
→ 血糖値が急降下する
→ 眠気・だるさが来る

これが「食後のあの眠さ」の正体です。

逆に言えば、
食後眠気が減ってきた＝血糖が安定してきた証拠。

体重より先に、ここが変わります。

↓続き（10/10）
```
