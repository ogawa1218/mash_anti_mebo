## 投稿2/10｜原因

```
夜遅く食べると太る科学的理由。

「BMAL1（ビーマルワン）」という体内時計遺伝子がある。

夜10時〜深夜2時に活性化し、
脂肪合成酵素が増える。

同じカロリーでも、
この時間帯に食べると脂肪になりやすい。

「夜遅く食べると太る」は根拠のある話だった。

↓続き（3/10）
```

---

## 投稿3/10｜解決策

```
食べる時間「3ルール」。

① 夕食は就寝3〜4時間前に終える
② 朝食は起床後1時間以内に食べる
③ 22時以降は食べない

食べる内容を変えなくていい。
食べる時間を変えるだけ。

意志力は要らない。

↓続き（4/10）
```

## 投稿4/10｜仕組み

```
なぜ「インスリン感受性」が昼夜で変わるのか。

朝〜昼：インスリン感受性 高い
→少ないインスリンで血糖を処理できる
→エネルギーとして使われやすい

夕方〜夜：感受性が低下
→同じ糖質でも血糖が上がりやすい
→脂肪として蓄積されやすい

体が「夜は休む」と判断するから起こる自然な変化。

Sutton et al. Cell Metabolism 2018

↓続き（5/10）
```

## 投稿6/10｜設計

```
「遅くなりやすい」を防ぐ時間設計。

23時就寝 → 19〜20時に食べ終える
24時就寝 → 20〜21時に食べ終える

コツは「帰宅したらすぐ着替えてすぐ食べる」。

帰宅→着替え→食事の順を
「習慣のセット」にする。

考えないで動ける設計が勝つ。

↓続き（7/10）
```

## 投稿8/10｜復帰

```

→ 昼食でしっかり食べる（インスリン感受性が高い）

「絶対に遅く食べない」じゃなくていい。
「翌日に補正できる」が続く。

8勝6敗でいい。

↓続き（9/10）
```

## 投稿9/10｜深掘り

```
「朝食を抜けばいいんじゃ？」は誤解。

朝食を抜く→空腹が強くなる→昼・夜に過食
→むしろ体内時計が乱れやすい

目指すのは「抜く」じゃなく「前にずらす」こと。

食事を早めに終わらせて、
翌朝しっかり食べる。

この循環を作ることが体内時計を整える。

↓続き（10/10）
```
