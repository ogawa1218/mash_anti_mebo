## 今回の内容

✅ **「プロテインより甘酒」は本当か**
→ 目的で使い分ける。筋量維持ならプロテイン、間食暴走対策なら甘酒置換

✅ **間食置換のメリット3つ**
→ 甘味欲をゼロにしなくていい / ルール化しやすい / 夜の過食を防ぐ（Ludwig, JAMA 2002）

✅ **失敗パターン4つ（正直に）**
→ 量が多い / 追加で飲む / お菓子と併用 / ルールがない

✅ **そのまま使える置換ルール4つ**
→ 量固定（100〜150ml）/ 時間固定（15〜17時）/ 単体ルール / 8勝6敗でOK

✅ **コスト比較：月5,000円以上浮く**
→ ポテチ+チョコ+菓子パン＝月10,000円超 → 甘酒置換＝月3,000〜4,500円
