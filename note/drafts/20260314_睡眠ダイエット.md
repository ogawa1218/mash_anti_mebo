# 痩せたいなら、まず睡眠を整えろ。睡眠を削るダイエットが逆効果な科学的理由

---

健診の結果を、家族に見せずに引き出しにしまったことはないか。

「また来年こそは」と思いながら、夜中にカップ麺を食べる。
睡眠は5〜6時間。仕事が忙しいから仕方ない。
でも体重は増え続けている。

もしあなたが「睡眠を削ってでも運動時間を作ろう」と考えているなら、今すぐやめてほしい。

逆効果だから。

## 結論から言う

**睡眠を削りながらダイエットすると、落ちる体重のうち脂肪が55%減少し、筋肉が60%多く失われる。**

これは「気がする」ではない。研究で確認されている数字だ。

睡眠不足の状態でカロリーを減らしても、体は脂肪より筋肉を優先して分解する。
筋肉が減れば基礎代謝が落ちる。基礎代謝が落ちれば、同じ食事でも太りやすくなる。

「痩せたいから睡眠を削る → 筋肉が落ちる → 基礎代謝が下がる → もっと太りやすい体になる」

この悪循環に、俺も100kgだった頃ハマっていた。

## なぜ睡眠不足で「筋肉から」落ちるのか

シカゴ大学の研究（Nedeltcheva et al., 2010）で面白いことが示された。

同じカロリー制限をしたグループを2つに分ける。
- グループA：1日8.5時間睡眠
- グループB：1日5.5時間睡眠

2週間後の体重減少は同じだった。でも中身が違った。

グループA（十分な睡眠）：失った体重の約80%が脂肪から
グループB（睡眠不足）：失った体重のうち脂肪からはわずか45%

睡眠不足グループは、脂肪が55%少なくしか減らず、代わりに筋肉が60%多く失われていた。

なぜか。答えはホルモンにある。

睡眠が不足すると：
- **コルチゾール（ストレスホルモン）が上昇** → 筋肉を分解してエネルギーを作ろうとする
- **グレリン（空腹ホルモン）が増加** → 食欲が制御できなくなる
- **レプチン（満腹ホルモン）が低下** → 満腹感が鈍くなる
- **成長ホルモンの分泌が激減** → 筋肉の修復と脂肪燃焼が止まる

つまり睡眠不足の体は、「脂肪を守りながら筋肉を削る」モードに入る。
ダイエットとまったく逆の方向に体が動くわけだ。

## 睡眠の「時間」より「規則性」が大事だった

さらに驚く話がある。

2023年にNature Communicationsに掲載されたUKバイオバンクの大規模研究（88,000人以上）で、こんな結論が出た。

**「睡眠の規則性（毎日同じ時間に寝て起きる）は、睡眠時間よりも強力な死亡リスク予測因子だった」**

毎日7時間以上寝ていても、就寝時間がバラバラなら効果が半減する。
逆に言えば、毎日同じ時間に寝起きするだけで、睡眠の質は大きく変わる。

俺が100kgから68kgになれたのは、運動や食事の前に「毎日同じ時間に寝る」を徹底したからだ。

アラームをセットするのは起きる時間だけじゃない。**寝る時間にもアラームをセットする。**

## 代謝と睡眠の意外な関係

「睡眠とダイエット」だけじゃない。睡眠不足は代謝そのものを壊す。

1日4〜5時間の睡眠が1週間続くだけで：
- インスリン感受性が40%低下（糖尿病リスク）
- 空腹時血糖が上昇
- 中性脂肪が増加

健診でE判定をもらったあなたの血糖値・HbA1cが改善しない理由の一つが、実は「睡眠不足」かもしれない。

薬を飲む前に、まず睡眠を整える。それが正しい順番だ。

## よくある失敗パターン

**「週末に寝だめすればいい」**
→ これはダメ。睡眠の「規則性」が壊れる。週末に2〜3時間遅く起きるだけで、月曜の代謝が週初めから悪化する。

**「睡眠アプリを入れたけど続かない」**
→ アプリより先に「寝る時間のアラーム」を設定するだけでいい。記録より習慣化が優先。

**「忙しくて7時間は無理」**
→ 7時間が無理なら、まず「毎日同じ時間に寝る」を優先する。時間は少なくても規則性が代謝を守る。
