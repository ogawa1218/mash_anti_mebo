## 🎨 noteに投稿する手順

### ステップ1：記事本文を投稿（5分）

1. `記事本文.md` を開く
2. 全文をコピー（Ctrl + A → Ctrl + C）
3. note エディタにペースト
4. プレビューで確認

### ステップ2：図解を生成（15分）

1. Genspark（https://www.genspark.com/）にアクセス
2. 「Nano Banana Pro」を選択
3. `図解プロンプト.md` を開く
4. 図解①のプロンプトをコピー＆ペースト
5. 生成された画像をダウンロード
6. 図解②〜⑤も同様に生成

**図解挿入位置：**
- 図解①：セクション3「食事改善で本当に必要なのは『順番』です」の後
- 図解②：セクション4「なぜ『順番』が大事なのか？」の中
- 図解③：セクション5「【ステップ1】夜の暴走ポイントを止める」の中
- 図解④：セクション6「【ステップ2】朝と昼に、たんぱく質の土台を足す」の中
- 図解⑤：セクション7「【ステップ3】夜外食の選び方テンプレを固定する」の中

### ステップ3：サムネイルを設定（10分）

1. `サムネイルプロンプト.md` を開く
2. 案A、B、Cから1つ選ぶ（推奨：案B）
3. Nano Banana Proでサムネイルを生成
4. 生成された画像をダウンロード
5. noteのサムネイル設定でアップロード

### ステップ4：タグを設定（1分）

以下のタグを設定：
- #ダイエット
- #メタボ
- #健康診断
- #食事管理
- #習慣化

### ステップ5：プレビュー確認（3分）

- 記事全体の流れを確認
- 図解が正しい位置に配置されているか
- サムネイルが魅力的か
- 誤字脱字がないか

### ステップ6：公開（1分）

- 「公開する」ボタンをクリック
- 公開URLをコピー

## 🐦 X告知の手順

### パターンA：1投稿版（すぐに告知したい場合）

1. `X告知文.md` を開く
2. 「1投稿版」をコピー
3. `[note URL]` を実際のnote URLに置き換え
4. Xに投稿

### パターンB：10連スレッド版（時間がある場合）

1. `X告知文.md` を開く
2. 「10連スレッド版」の1/10から順にコピー
3. Xでスレッド形式で投稿
4. 最後の10/10の`[note URL]`を実際のURLに置き換え
