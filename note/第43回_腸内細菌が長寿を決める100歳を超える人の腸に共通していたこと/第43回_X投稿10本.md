## 投稿1/10｜共感

## 投稿2/10｜原因

```
なぜヨーグルトだけでは変わらないのか。

腸内細菌は「競争」で生き残る。
外から入った善玉菌は、餌がなければ
すぐに洗い流されてしまう。

餌＝プレバイオティクス（食物繊維・オリゴ糖）

ヨーグルトに
バナナかはちみつをプラスするだけで
定着率が劇的に変わる。

↓続き（3/10）
```

## 投稿3/10｜解決策

```
今夜からできる腸活3ステップ。

② 主食：大麦2割混ぜ（食物繊維3〜4倍）
③ 食後：15分ウォーキング

全部やらなくていい。
1つだけ選べばいい。

それで腸内細菌は動き始める。

↓続き（4/10）
```

## 投稿4/10｜仕組み

```
なぜ「大麦」が腸にいいのか。

大麦にはβ-グルカンという水溶性食物繊維が豊富。
これが「酪酸産生菌」の大好物なんです。

酪酸産生菌→酪酸を産生→腸細胞のエネルギー源に
→腸管バリアが強化→慢性炎症が抑制される

白米100%を白米8割＋大麦2割に変えるだけ。
炊飯器で一緒に炊けばOK。

↓続き（5/10）
```
