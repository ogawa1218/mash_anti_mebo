## 投稿2/10｜原因

```
シャワーで終わると眠れない理由。

人は「深部体温が下がるとき」に眠気が来やすい。

シャワーだけ → 全身が温まらない
→ 体温変化が起きない
→ 眠気のスイッチが入りにくい

湯船とシャワーの差は、
「気持ちの問題」じゃなく「体温の設計」の問題だ。

↓続き（3/10）
```

## 投稿3/10｜解決策

```
睡眠を変えた「入浴3原則」。

① 38〜40℃で10〜15分
② 就寝1〜2時間前に入る
③ 入浴後の流れを整える

これだけ。
ジムもサプリも器具もいらない。
湯船があれば今夜から試せる。

↓続き（4/10）
```

## 投稿6/10｜設計

```
「入れない日が続く」を防ぐ時間設計。

23時就寝 → 21〜22時に入浴
24時就寝 → 22〜23時に入浴

コツは「帰宅したらすぐ脱ぐ」。

これだけでタイミングが固定されやすい。

帰宅→着替え→入浴の順を「習慣のセット」にする。
考えないで動ける設計が勝つ。

↓続き（7/10）
```

## 投稿9/10｜深掘り

```
「熱いほど効く」は誤解。

43℃以上のお湯は交感神経を刺激しやすく、
むしろ覚醒方向に動く人が多い。

研究で使われているのは40〜42.5℃が中心。
個人差があるため「気持ちよく入れる温度」が正解。

「熱い＝すごい」じゃない。
「適温＋継続」が勝つ設計。

↓続き（10/10）
```
