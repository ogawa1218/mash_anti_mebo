# 「シャワーで十分」は損してる ― 就寝前の入浴で睡眠の質が変わる3つの理由

## 1. また今日も、シャワーだけで終わった

帰宅は22時を回っていた。

食事して、風呂入って、寝るだけ。

そう思って浴室に入ったけど、疲れていたから3分シャワーで済ませた。

「まあいっか。体は洗ったし」

ベッドに入っても、なんか眠れない。スマホをいじって、気づいたら0時を過ぎていた。

朝は6時のアラームで起きるけど、スッキリしない。なんとなくだるい。コーヒーを2杯飲んでやっと動ける。

僕が100kgだった頃、これが毎日だった。

「眠りが浅いのは仕事が忙しいせいだ」
「疲れているから当然だ」

そう自分に言い聞かせていたけど、本当は違った。眠れない夜の原因のひとつは、**シャワーだけで終わらせていたこと**だった。

これを知ったとき、正直「そんなことか」と思った。でも実際に変えてみたら、寝つきが変わった。朝の感覚が変わった。特別な運動もサプリも追加していないのに、体が少し軽くなった。

今日は、その話をする。

## 2. 睡眠を変えたのは、体温の「設計」だった

「入浴と睡眠になんの関係があるのか」

最初はそう思っていた。でも仕組みを知ると、かなりすっきりする。

人は、**深部体温が下がるタイミングで眠気が強くなりやすい**。

表面の皮膚の温度じゃなくて、体の内側の温度の話だ。

就寝1〜2時間前に湯船に浸かると、いったん体が温まる。でも、お風呂から出たあと、その熱が皮膚を通じて外に逃げていく。この「温まって、そのあと下がる」流れが、脳にとって「そろそろ眠る時間だ」というサインになりやすい。

2019年、テキサス大学オースティン校のHaghayegh氏らが発表したメタ分析（*Sleep Medicine Reviews*）では、40〜42.5℃のお湯に就寝1〜2時間前に10分以上浸かると、入眠までの時間短縮と睡眠効率の改善が統計的に示された。このとき、末梢血流の増加（手足から熱が逃げる）と深部体温の低下が、入眠潜時短縮のメカニズムとして整合的だとまとめられている。

さらに2025年の観察研究（*Sleep Health* 誌掲載）では、就寝前に湯船に入った人は、入らなかった人と比べて睡眠効率が高く、夜中に目が覚める時間が短く、自己申告でも「よく眠れなかった」と感じる割合が低かった。

「気がする」の話ではなく、**客観的な睡眠指標が動いていた**のだ。

シャワーにも一定の可能性はあると研究では認めている。ただ、全身を温めて体温変化を起こしやすいのは湯船のほうが有利で、2025年の実生活研究も「湯船入浴」での関連を示した。だから、睡眠改善を狙うなら湯船を優先する価値が高い。

## 3. この記事でわかること ― 3つの結論

難しい話は後でする。まず結論を3つ先に言う。

**結論①：就寝1〜2時間前の温浴は、寝つきを良くし睡眠の質を上げる可能性がある**

深部体温の変化が入眠を助けるメカニズムとして整合的で、複数の研究がこれを支持している。

**結論②：これは「気分の話」じゃない。客観的な睡眠指標が改善する**

睡眠効率、中途覚醒時間、主観的睡眠評価――すべてに関連が見られている。

**結論③：「38〜40℃、10〜15分、就寝1〜2時間前」が、最も再現しやすい入口だ**

完璧な入浴環境を一気に作る必要はない。まずこの3つの数字を守るだけでいい。

## 4. E判定メタボ男性に、これがなぜ直撃するのか

健診E判定のメタボ男性には、こういう負のループがある。

仕事で疲弊する → 帰宅が遅い → シャワーで終わる → スマホをいじる → 眠れない → 朝がだるい → 甘いものやカフェインでごまかす → 夜食に手が出る → また崩れる

睡眠の質が下がると、睡眠だけの問題で終わらない。

グレリン（空腹ホルモン）が増え、レプチン（満腹ホルモン）が下がる。インスリン感受性が下がり、太りやすい体質方向に動く。ストレスへの耐性が落ちて、夜食の衝動に負けやすくなる。

つまり、眠れない夜は、**次の日の崩れを準備している**ことになる。

逆に言えば、睡眠の入口を1つ整えるだけで、連鎖が変わる可能性がある。

入浴はそのための、ほぼコストゼロの手段だ。ジムもいらない。サプリもいらない。湯船があるなら、今日から試せる。僕が最初にそこから変えたのも、同じ理由だ。

## 5. やりがちな3つの誤解 ― 逆効果パターンを先に潰す

**誤解①：「寝る直前に入るほどいい」**

これはズレやすい。直前に入ると、まだ体が熱いまま布団に入ることになりやすく、体温が下がる時間がない。就寝1〜2時間前に入るから意味がある。23時に寝たいなら、21〜22時に入浴するイメージだ。メタ分析でも、就寝1〜2時間前が最も一貫して入眠潜時短縮と関連していた。

**誤解②：「熱いお風呂ほど効く」**

熱すぎるお湯（43℃以上）は交感神経を刺激しやすく、むしろ覚醒方向に動きやすい。最初の実装は38〜40℃。少しぬるいと感じるくらいでいい。研究で使われているのは40〜42.5℃が多いが、個人差があるため「気持ちよく入れる温度」から始めるのが正解だ。「熱い＝効果大」ではない。

**誤解③：「シャワーでも同じ」**

完全にゼロではないが、湯船とは効果の出方が違う。湯船のほうが全身を温めやすく、その後の体温低下も起きやすい。2025年の観察研究が「湯船入浴」での関連を示しているのも、この違いが理由の一つだ。シャワーが全く無意味というわけではないが、睡眠の改善を狙うなら湯船を優先する価値が高い。

## 6. 「疲れていてもできる」入浴3コツ

**コツ①：温度と時間を固定する**

38〜40℃で10〜15分。

長く入りすぎない。熱くしすぎない。「気持ちよく入れて、翌日に体が残らない」を優先してほしい。

メタ分析では10分以上での効果が確認されている。15分を超えるとのぼせやすくなる人もいるので、最初は10〜12分からがちょうどいい。

僕の実体験を言うと、100kgの頃は「疲れてるし5分でいい」とやっていた。今は「疲れているほど10分入る」に変えた。入浴後の眠気の質が、体感として明らかに違う。

**コツ②：就寝の1〜2時間前に入る**

23時就寝なら21〜22時入浴。24時就寝なら22〜23時入浴。

最初は「帰宅したらすぐ入る」ルールにすると固定しやすい。帰宅時間がバラバラな人は、「帰ったらまず脱ぐ」というトリガーをセットすることで、入浴のタイミングが後ろにズレにくくなる。

**コツ③：入浴後は「眠る流れ」を邪魔しない**

せっかく体を整えても、その後の行動で台無しになることがある。

入浴後の「眠りの邪魔リスト」：スマホの強い光・興奮するSNSや動画・カフェイン（18時以降は控えると効果的）

入浴後の「眠る流れ設計」：軽いストレッチ・照明を少し暗くする・白湯やハーブティー・読書（スマホ以外）

お風呂単体で勝とうとしない。**入浴後の流れまでセットで設計する**のが強い。

## 7. 入れなかった日の「翌日リカバリー」

「昨日は疲れていて湯船に入れなかった」

そういう日はある。必ずある。ここで自己嫌悪に入ると、次の日も崩れやすい。

僕の基準は**「8勝6敗でいい」**だ。

14日のうち8日入れたら、十分に前進している。

**入れなかった日の翌朝にやること：**
- 朝シャワーを少し長めに（3〜5分）浴びる
- 「今日の夜は絶対入る」ではなく「機会があれば入る」くらいの設定にする
- 自己嫌悪に0秒使う。次の1手だけ考える

一晩シャワーで終わっても、次の日から再開できる。それだけでいい。
